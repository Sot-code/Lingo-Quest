# LingoQuest

An open-source web application designed to help students expand their vocabulary and support language learning.

## Live Demo & Project Link
- **Web App:** https://sot-code.github.io/Lingo-Quest/
- **GitHub Repository:** https://github.com/Sot-code/Lingo-Quest

## Tech Stack
- **Frontend:** FlutterFlow, JavaScript
- **Backend & Hosting:** Firebase, GitHub Pages / Cloudflare Pages
- **AI Integration:** Claude API for code generation and features

## Key Features
- Interactive vocabulary-building interface for language learners.
- Version-controlled development via GitHub with clean commit histories.
- Collaborated on user feedback and testing with local community non-profit programs.
